# Verification: the account screens, the player bar, and the cross-cutting concerns

How to run this file: bring up `npx vercel dev` at `http://localhost:3000` as described in [the protocol](README.md). Device values are defined in [the protocol](README.md#devices-and-conditions).

This is the cluster with the most prerequisites, because it is the cluster about conditions rather than screens. Before starting:

- **Both accounts**, as the protocol asks for: one created with **CONTINUE WITH SPOTIFY** and one created with an email address. Every SIGNIN item about the two ways in needs both, and the whole of RESET needs the email one.
- **A working mail configuration** for the authentication service. `RESET-01` is the gate: if no reset email arrives, `RESET-03` to `RESET-09` cannot be run at all and are all `blocked`.
- **Spotify Premium on a desktop browser** for BAR-01 to BAR-19. A free Spotify account for `BAR-03`, `SPOT-07`, and `SPOT-08`; if only one Spotify account is available, those three are `blocked`.
- **A real network switch** — wifi off, not devtools throttling — for `BAR-14`. Devtools' Offline profile does not reach the Web Playback SDK's own connection, so the music keeps playing and the item proves nothing.
- **Something worth having in the library** for the FAIL and STALE items: a settings value changed from the default (for `FAIL-05`), some duplicates (for `FAIL-11`), and enough records that an empty screen is obviously wrong rather than correct.

Two items in other files belong to this cluster's subject and are **not repeated here**, because running the same test twice under two IDs would double the destructive work: the library's crate-destroying save is [`SAVE-05`](library.md), and the empty GAPS audit on a direct `/library` visit is [`AUDIT-01`](library.md). Run each there, once.

The FAIL items are the most valuable pass in this repo and the cheapest to run — devtools' Offline throttle, the console open, and a walk through the product. Do them in order; `FAIL-01` is the sweep and the rest are its individual claims.

Not checkable by hand:
