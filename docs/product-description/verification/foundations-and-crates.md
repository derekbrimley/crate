# Verification: foundations and crates

How to run this file: bring up `npx vercel dev` at `http://localhost:3000` as described in [the protocol](README.md). Most of this file needs a **linked Spotify account with a populated library** — at least thirty records, some favorites and some recommendations, and at least one record picked in the last three days — plus a **fresh account** for the seeding and empty-state items, and an **email-only account** for the account-state items. Every crate must be at its seeded default unless an item says otherwise; if a previous item edited a crate, delete it and re-seed by using a new account rather than trying to restore it by hand. Device values are defined in [the protocol](README.md#devices-and-conditions).

Run `DATA` and `ACCT` first: they establish what the rest of the file assumes.
