# Verification: the library

How to run this file: bring up `npx vercel dev` at `http://localhost:3000` as described in [the protocol](README.md). Everything here works on an **email-only** account except the items about playback and the player bar's padding, so this is the cheapest cluster to run. Device values are defined in [the protocol](README.md#devices-and-conditions).

Two things decide almost every item in this file, and both are about **how the tab arrived**:

- A tab that reached the library *through the crate wall* has the pick history and the crate definitions in its [session cache](../foundations/navigation-and-loading.md).
- A tab opened **directly** at `http://localhost:3000/library` has neither, and behaves differently in eight of the items below.

Where an item says "fresh tab, direct to `/library`", it means exactly that: a new tab, the URL typed or pasted, nothing visited first. Reloading on `/library` is the same thing.

> **Run `SAVE-05` last, and only on an account whose crates you are willing to lose.** It is expected to delete every crate on the account, and there is no undo. Everything else in this file is safe apart from the deletions in `AUDIT`, which are the ordinary destructive path and should be run on records you do not mind losing.
