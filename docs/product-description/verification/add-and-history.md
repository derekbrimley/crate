# Verification: adding records and the listening log

How to run this file: bring up `npx vercel dev` at `http://localhost:3000` as described in [the protocol](README.md). The SEARCH and LOG items run on any signed-in account, including an **email-only** one. Every IMPORT and PLIST item except the connect-prompt ones needs a **linked Spotify account with saved albums and playlists**. Device values are defined in [the protocol](README.md#devices-and-conditions).

Three things to have ready before starting:

- **A Spotify account with at least 60 saved albums**, so `IMPORT-05` has a second page to load, and **at least one playlist of 150+ tracks**, so `PLIST-03` has something to reduce.
- **An account with more than 100 picks**, for `LOG-04`. There is no way to make one quickly: a hundred taps on the crate wall is the only path, so this item may stay `blocked`.
- **An empty-ish account** for the genre items — the difference between a record filed by search and one filed in bulk is the single most consequential thing in this cluster, and it is easiest to see on an account where you control both.

The add screen is not in the bottom navigation. Reach it from the round orange button in the library's header, or type `http://localhost:3000/add`.
